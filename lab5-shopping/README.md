# Lab 5 — Shopping

## 📝 Overview
This lab implements a k-nearest neighbors classifier to predict whether online shopping sessions result in purchases.

## 🧠 Concepts Covered
- k-NN classification
- Data preprocessing
- Evaluation metrics (accuracy, sensitivity, specificity)
- Feature engineering

## 📂 Files
- `shopping.py` — main solution  
- `shopping.csv` — dataset (ignored in GitHub)

## ▶️ How to Run
python3 shopping.py shopping.csv

## 🧪 Notes
This lab introduces supervised learning and the importance of evaluation metrics beyond accuracy.
