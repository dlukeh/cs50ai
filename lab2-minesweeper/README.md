# Lab 2 — Minesweeper

## 📝 Overview
This lab implements an AI agent that plays Minesweeper by reasoning about safe cells and mines using logical inference.

## 🧠 Concepts Covered
- Constraint satisfaction
- Knowledge representation
- Inference rules
- Safe move detection

## 📂 Files
- `minesweeper.py` — game logic and AI  
- `runner.py` — graphical interface

## ▶️ How to Run
python3 runner.py

## 🧪 Notes
The AI builds and updates a knowledge base of constraints, allowing it to deduce safe moves and mine locations.
