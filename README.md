# 🧠 CS50AI — Artificial Intelligence with Python
## 🧰 Skills Demonstrated
- Python (intermediate–advanced)
- Search algorithms (BFS, DFS, A*)
- Logic and inference (model checking, propositional logic)
- Constraint satisfaction (CSPs, backtracking, heuristics)
- Probability and Bayesian networks
- Machine learning (k-NN, evaluation metrics)
- Deep learning (CNNs with TensorFlow/Keras)
- Error analysis and model interpretation
- Clean code organization and documentation

## 🗂 How to Navigate This Repo

Each lab is self-contained inside its folder:

- `lab0-search/` — graph search algorithms  
- `lab1-knowledge/` — logic and inference  
- `lab2-minesweeper/` — constraint reasoning  
- `lab3-heredity/` — Bayesian networks  
- `lab4-crossword/` — CSPs and heuristics  
- `lab5-shopping/` — k-NN and evaluation  
- `lab6-traffic/` — CNNs and image classification  
- `lab7-language/` — n-gram language models (in progress)
