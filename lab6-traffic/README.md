# Lab 6 — Traffic

## 📝 Overview
This lab trains a convolutional neural network (CNN) to classify traffic signs using the GTSRB dataset.  
It includes additional experiments analyzing misclassified images.

## 🧠 Concepts Covered
- Convolutional neural networks
- Image preprocessing
- Softmax classification
- Model evaluation
- Error analysis

## 📂 Files
- `traffic.py` — main solution  
- `traffic_experiments.py` — misclassification visualization  
- `MODEL_REPORT.md` — detailed model behavior report  
- `gtsrb/` — dataset (ignored in GitHub)

## ▶️ How to Run
python3 traffic.py

## 🧪 Notes
The experiment file provides deeper insight into model weaknesses and generalization behavior.
