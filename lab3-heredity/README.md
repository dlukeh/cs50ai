# Lab 3 — Heredity

## 📝 Overview
This lab models genetic inheritance using Bayesian networks.  
The program computes probabilities of gene expression and traits across family trees.

## 🧠 Concepts Covered
- Bayesian networks
- Joint probability distributions
- Conditional probability
- Enumeration algorithms

## 📂 Files
- `heredity.py` — main solution  
- `data/` — family datasets (ignored in GitHub)

## ▶️ How to Run
python3 heredity.py data/family0.csv

## 🧪 Notes
This lab builds intuition for probabilistic reasoning and uncertainty modeling.
