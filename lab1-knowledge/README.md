# Lab 1 — Knowledge

## 📝 Overview
This lab uses propositional logic to model knowledge and perform inference.  
The system determines whether characters are knights (truth-tellers) or knaves (liars) based on logical statements.

## 🧠 Concepts Covered
- Propositional logic
- Model checking
- Logical inference
- Knowledge bases

## 📂 Files
- `logic.py` — logic engine  
- `puzzle.py` — puzzle definitions and solver

## ▶️ How to Run
python3 puzzle.py

## 🧪 Notes
This lab demonstrates how AI systems can reason about truth, constraints, and logical consistency.
